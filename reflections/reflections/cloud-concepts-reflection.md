# Cloud Concepts Reflection

## 1. Cloud Services I Use Regularly
Three cloud services I interact with regularly are:
- **Google Drive:** Used for storing, creating, and collaborating on academic documents and spreadsheets in real time.
- **Canva:** Used for creating visual graphics, presentations, and design projects directly inside the browser.
- **Netflix:** Used for streaming digital media on demand across multiple devices.

## 2. Service and Deployment Models Analysis
- **Google Drive**
  - *Service Model:* **SaaS (Software as a Service)** because it offers a complete, ready-to-use software application to end-users without requiring server management.
  - *Deployment Model:* **Public Cloud** because Google hosts and manages the service on public infrastructure accessible to internet users globally.
- **Canva**
  - *Service Model:* **SaaS (Software as a Service)** as it provides a cloud-native design platform accessible via browser or application.
  - *Deployment Model:* **Public Cloud** since it relies on shared public cloud infrastructure (such as AWS) accessible to any registered user.
- **Netflix**
  - *Service Model:* **SaaS (Software as a Service)** delivering media consumption applications directly to consumer devices.
  - *Deployment Model:* **Public Cloud** built on public cloud infrastructure (AWS) to scale globally.

## 3. Importance of Git & GitHub for Cloud Projects
Version control is essential when working with cloud infrastructure, especially as environments are defined through code (Infrastructure as Code). Git enables engineering teams to track every configuration change, perform peer reviews, and rollback to earlier stable versions if deployment errors occur. GitHub provides a secure centralized hub for team collaboration, code auditing, and automated CI/CD deployments.
